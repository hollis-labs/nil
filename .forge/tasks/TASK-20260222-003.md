## Description
Create `chat/bridge.go` implementing the Claude API call. Takes a session context (vault name, capabilities, dry_run flag), user message, and optional vault search results. Returns a `ChatResponse` containing the assistant text and optionally a parsed `ActionProposal`.

## Paths
- `chat/bridge.go` (new)

## Acceptance Criteria
- [ ] `Bridge.Send(ctx, req BridgeRequest) (*ChatResponse, error)` implemented
- [ ] System prompt injects vault context (name, caps, dry_run), current date
- [ ] User message + any search results sent to Claude as `messages` array
- [ ] Response parsed: extract plain text and optionally a JSON action block
- [ ] If JSON action present → populate `ChatResponse.Proposal` (`ActionProposal` stub, not yet persisted)
- [ ] If API key missing/invalid → return descriptive error (no panic)
- [ ] Uses `net/http` directly (no external SDK dependency to keep Go module clean)
- [ ] `go build .` passes
