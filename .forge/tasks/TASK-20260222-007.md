## Acceptance Criteria
- [ ] Shows action type badge: CREATE | UPDATE | DELETE (color-coded via theme vars)
- [ ] Shows item type: todo | note
- [ ] Shows target vault name
- [ ] For UPDATE: renders a diff table (field, old value, new value)
- [ ] For CREATE: renders all proposed field values
- [ ] For DELETE: renders item title + confirmation warning
- [ ] "Approve" button: calls `Backend.ApproveChatAction(proposalID)`; on success shows "Executed ✓"

- [ ] Dry-run mode: buttons still present but execution shows "Dry run — not executed"
- [ ] Post-resolution: buttons disabled; status displayed
- [ ] Uses only `var(--term-*)` CSS variables
- [ ] Uses standard `<button>` elements (not divs) for WKWebView click compatibility
