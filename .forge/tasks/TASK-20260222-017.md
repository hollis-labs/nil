## Description
Add a `create_item` tool so Claude can create items directly (without the propose→approve flow) when the vault has `DirectCreate` permission enabled. Adds the `directCreate` cap to config, bridge, app.go, and Settings UI.

## Paths
- `config/config.go` — `DirectCreate bool` added to `VaultCap`
- `chat/bridge.go` — `VaultCaps.DirectCreate`; `create_item` tool; `executeCreateItem`; `executeTool` accepts `caps`; capabilities line + mutation instructions updated
- `app.go` — both `VaultCaps{}` literals pass `DirectCreate: vc.DirectCreate`
- `frontend/wailsjs/go/models.ts` — regenerated via `wails generate module`
- `frontend/src/components/SettingsModal.tsx` — directCreate column in vault caps grid

## Acceptance Criteria
- [x] `DirectCreate bool` in `config.VaultCap`
- [x] `create_item` tool registered in `buildTools()` with full JSON schema
