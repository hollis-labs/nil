## Description
Create `src/components/ChatPanel.tsx` — the main chat UI container. Manages session lifecycle, renders the message thread, input box, and session status.

## Paths
- `frontend/src/components/ChatPanel.tsx` (new)
- `frontend/src/components/ChatMessage.tsx` (new)

## Acceptance Criteria
- [ ] `ChatPanel` renders as a floating/overlay panel (position: fixed, right side or center)
- [ ] On mount: calls `Backend.StartChatSession()`, stores session ID
- [ ] On unmount/close: calls `Backend.EndChatSession(sessionID)`
- [ ] Input: text area; Enter submits (Shift+Enter for newlines), sends to `Backend.SendChatMessage`
- [ ] Message thread: scrolls to bottom on new message; renders `ChatMessage` per turn
- [ ] Loading state: shows "..." indicator while awaiting response
- [ ] Error state: if response contains error (missing API key, etc.) renders error message in red
- [ ] Uses only `var(--term-*)` CSS variables for all colors
- [ ] Panel has a close button (calls onClose prop)

## Verification

```bash
# After wiring into App.tsx:
wails dev
# Open chat panel → see empty thread → type a message → see response
```
