## Description
Add `notes_text TEXT` column to `todos` table. This is the HTML-stripped, plain-text version of `notes_md`. Used for FTS5 indexing and AI tool results. Improves both search quality (no HTML token noise) and token efficiency in Claude responses.

See ADR-002 for full rationale.

## Paths
- `store/schema.sql` — add `notes_text TEXT` column
- `store/store.go` — migration v5 (ALTER TABLE + FTS5 rebuild + backfill), `stripHTML()` helper
- `store/store.go` — `CreateItem` + `UpdateItem` populate `notes_text` from `notes_md`
- `store/store.go` — FTS5 content column updated to use `notes_text`
- `chat/bridge.go` — `executeSearchVault` and future `executeGetItem` use `notes_text` not `notes_md`

## Acceptance Criteria
- [ ] `notes_text TEXT` in schema.sql (fresh install)
- [ ] Migration v5: ALTER TABLE todos ADD COLUMN notes_text TEXT (IF NOT EXISTS guard)
- [ ] FTS5 virtual table updated: `notes_text` indexed instead of (or alongside) `notes_md`
- [ ] `stripHTML(s string) string` helper in store package — no CGo, handles `<p>`, `<br>`, `<ul>/<li>`, `<strong>`, `<em>`, `<h1-h6>`; preserves paragraph breaks as `\n\n`
- [ ] `CreateItem` + `UpdateItem` set `notes_text = stripHTML(notes_md)` on save
- [ ] One-time backfill in migration: `UPDATE todos SET notes_text = ... WHERE notes_text IS NULL`
- [ ] AI tool result: `executeSearchVault` uses `notes_text` (no more raw HTML in Claude context)
- [ ] `store.Item.NotesText string` field exposed in Go struct + Wails model
- [ ] `go build .` + `npx tsc --noEmit` clean

## Notes
- currentSchemaVersion in store.go must be bumped to 5
- FTS5 rebuild is a DROP + CREATE IF NOT EXISTS on `todos_fts` with updated content columns
- The `stripHTML` helper does NOT need to be perfect — good enough for search and AI context
- Consider stripping common TipTap classes/attrs: `data-type`, `class`, etc.

## Priority Justification
Elevated to Sprint 1 / Priority A: FTS5 quality and AI token efficiency both benefit immediately. Every search_vault tool result currently sends HTML to Claude, wasting context window.
