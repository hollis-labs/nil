## Description
Log every tool invocation to `chat.db` for audit and future RAG. Cache results in-memory per session so repeat or near-identical tool calls avoid DB round-trips.

## Acceptance Criteria
- [x] `chat_tool_calls` table in `chat.db` (session_id, message_id, tool_name, input_json, result_json, cache_hit, created_at)
- [x] `ChatStore.PersistToolCall()` + `GetRecentToolCalls()` methods
- [x] `ToolCallRecord` type in models.go (tool_name, input_json, result_json, cache_hit)
- [x] `ToolCache` type in models.go: FIFO eviction, max 20 entries, thread-safe
- [x] `BridgeRequest.ToolCache *ToolCache` — nil-safe, passed from app.go
- [x] `Bridge.executeTool()` checks cache before store, populates cache after; returns (result, cacheHit)
- [x] `ChatResponse.ToolCalls []ToolCallRecord` — all tool calls for this turn
- [x] `app.go`: `sessionCaches map[int64]*chat.ToolCache`, created lazily, freed on `EndChatSession`
- [x] `app.go`: after `Send()`, persists each ToolCallRecord (best-effort, non-fatal)
- [x] `go build .` clean
