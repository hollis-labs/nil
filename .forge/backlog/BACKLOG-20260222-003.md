## Description
Allow chat to search across multiple vaults in a single query, merging and ranking results. Currently chat targets only the active vault.

## Value
Power users with multiple vaults (e.g. work/personal) want unified search without switching.

## Notes
- Requires vault capability changes (each vault must allow read for cross-search)
- LLM context window grows with more search results — may need summarization
- Estimate: 1–2 iterations
