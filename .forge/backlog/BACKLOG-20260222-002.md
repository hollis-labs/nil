## Description
A chat mode focused on processing inbox items: AI presents each inbox item, suggests classification (project, context, tags, section), and user approves or adjusts via chat. Builds on ActionProposal flow.

## Value
Reduces friction for users who capture quickly and want AI-assisted classification during triage sessions.
