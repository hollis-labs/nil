## Description
Split the context cache into per-vault and per-project files so agents can fetch granular context (e.g., `vault_<id>.json`, `project_<slug>.json`) without loading the full snapshot. Add CLI verbs like `nanite context vault <id>` and `nanite context project <name>` that read these finer caches.

## Notes
- Requires cache invalidation when a specific vault/project changes.
- Enables agents to stream targeted context quickly when orchestrating multi-vault workflows.
