## Description
A rule-based classifier that scans proposed action payloads and automatically assigns project/context/tag taxonomy based on user-defined keyword rules. Runs before the ActionProposal is shown to the user.

## Value
Reduces manual taxonomy assignment for users with consistent naming conventions.

## Notes
- Rules stored in `chat.db` or NANITE config
- Applies to create and update proposals only
- Could use a simple YAML rule file for MVP: `{keyword: "meeting", add_context: ["@meetings"]}`
- Estimate: 1 iteration
