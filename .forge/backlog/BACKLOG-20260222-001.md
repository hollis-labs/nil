## Description
Allow users to name and save chat sessions. Named sessions can be reopened to continue a conversation, with full message history restored from `chat.db`.

## Value
Users working on long-running projects want to maintain context across multiple NANITE sessions without re-explaining their context each time.

## Notes
- Depends on M2 completion (chat.db fully operational)
- UI: session list in chat panel sidebar or dropdown header
- Estimate: 1 iteration (1 task, M1 pattern)
