## Description
Capture dated copies of the agent context snapshot (e.g., `snapshot-YYYYMMDD.json`) so agents can compare states over time without hitting the DB. Provide CLI hooks like `nanite context history --since <date>` to list or stream past snapshots.

## Notes
- Add retention + pruning strategy to avoid unbounded storage.
- Useful for trend analysis, weekly reports, or RAG prompts that reference "last week's state".
