## Description
Implement `nanite add --file` and `nanite import --dir` so both humans and agents can ingest external content using the same routing rules as the GUI. The first iteration must only accept UTF-8 plain text or Markdown sources; anything else should return a typed error encouraging the user to convert their file. Metadata flags (vault, inbox, type, meta, title) need to be available at import time.

## Requirements
- Detect binary vs UTF-8 text up front; abort with `ok:false` and a clear `error` field when unsupported content is encountered.
- Treat Markdown as raw text storage for now (no conversion); apply the existing processing rules (inbox routing, tags, contexts) exactly as if the body were typed on the CLI.
- Directory imports iterate recursively but honor a `--limit`/`--batch-size` to prevent runaway ingestion.
- Emit a single summary JSON envelope listing successes/failures so agents can make decisions.
