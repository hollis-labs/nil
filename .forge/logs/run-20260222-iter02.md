## Notable Decisions

| Decision | Rationale |
|---|---|
| chat.db separate from vault DBs | Spec requirement; prevents chat history polluting user vault |
| `net/http` for Claude API (no SDK) | Keeps go.mod clean; Claude API is simple enough |
| Bridge is stateless | Simplifies testing; all state managed by ChatStore |
| Always run FTS5 search on every SendChatMessage | Simple, effective context injection for MVP; can be made conditional post-MVP |
| VaultCaps default read-only | Safety-first; write/delete must be explicitly enabled per vault |
| `GetConfigDir()` exported | Clean dependency injection for chat package (no circular import) |
