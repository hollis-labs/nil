## TASK-20260222-010 — Settings: chat config section

**Files changed:**
- `frontend/src/components/SettingsModal.tsx`

**What was done:**
1. Added `'chat'` to `SettingsTab` union type.
2. Defined `ChatConfigState` local plain-object type (avoids Wails class `convertValues` method spread issue).
3. Added `chatConfig: ChatConfigState | null` and `chatApiKeyVisible: boolean` state.
4. `useEffect` on `open`: calls `Backend.GetChatConfig()` and extracts plain fields into `chatConfigState`.
5. `handleSave`: also calls `Backend.SetChatConfig(chatConfig as config.ChatConfig)` when chatConfig is loaded.
6. Tab bar: changed Vaults button `borderRadius` from `'0 4px 4px 0'` to `'0'`; added Chat button with `'0 4px 4px 0'`.
7. Chat tab content:
   - **Enable Vault Chat** toggle (checkbox style matching showCompleted)
   - **Claude API Key** password input with Show/Hide toggle button
   - **Model** `<select>` dropdown (Haiku default, Sonnet option)
   - **Dry-run mode** toggle (checkbox style)
   - **Vault Permissions** grid table: one row per vault, Read/Write/Delete checkbox toggles; uses existing `vaults` state already loaded on open

**Key decision — type casting:**
Wails-generated `config.ChatConfig` is a class with `convertValues`. Spreading it loses the method and TypeScript errors.
Solution: `ChatConfigState` plain type for React state; `as config.ChatConfig` cast on save (structurally compatible at runtime).
