### Design notes
- `list_templates` omits the `prompt` field to keep tool result tokens low; Claude only needs slug/name/description to select the right template
- `use_template` leaves unsubstituted `{{params}}` as-is; Claude can fill them from conversation context
- Template tools are dispatched before the `st == nil` guard since they don't touch the vault store
